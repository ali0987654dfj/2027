# منصة السادس

موقع ثابت بدون لوحة تحكم، مبني على `data.json`.

## الملفات
- `index.html` الواجهة
- `style.css` التصميم
- `app.js` وظائف الموقع وتشغيل المحاضرات
- `data.json` بيانات المدرسين والمحاضرات
- `netlify.toml` إعداد Netlify

## الرفع على GitHub / Netlify
ارفع محتويات هذا المجلد إلى المستودع، ثم اربط المستودع بـ Netlify.
لا يوجد مجلد `netlify/functions` ولا إعداد Functions، لذلك لا يظهر خطأ Functions السابق.

ملاحظة: روابط الفيديو الموجودة في `data.json` هي التي يتم استخدامها كما هي. تشغيل روابط HLS يعتمد أيضًا على السماح بها من خادم الفيديو (CORS) وعلى صلاحية الرابط.
