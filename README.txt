# منصة السادس

موقع تعليمي عربي RTL مبني على `data.json`، ومصمم بروح الواجهة المرفقة:
- صفحة رئيسية متجاوبة للموبايل.
- المواد الدراسية والمدرسون والمحاضرات تُقرأ مباشرة من data.json.
- بحث عن مدرس/مادة/فصل/محاضرة.
- صفحة مدرس داخل نافذة منبثقة مع الفصول.
- تشغيل روابط HLS (m3u8) وروابط YouTube.
- شريط تنقل سفلي للموبايل.

## التشغيل
يفضل تشغيله عبر خادم محلي لأن المتصفح قد يمنع `fetch('data.json')` عند فتح index.html مباشرة.

مثال:
`python -m http.server 8000`

ثم افتح:
`http://localhost:8000`

## Netlify
ارفع محتويات المجلد كما هي إلى Netlify. لا تحتاج Backend لهذا الإصدار.
